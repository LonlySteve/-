# 点对点回答契约

本文件是作答 agent 与审计 agent 共同的判据。冲突时以此为准。

---

## 1. 唯一目标

**图上（题库里）有多少个原子核对项，报告里就有多少行只属于它自己的答案。**

不是"答得漂亮"，而是"一条不漏、一条不糊"。分母由 `question_bank.json` 决定，不由模型判断。

---

## 2. 格式契约

每个节点一个区块：

```markdown
### [F01] 公司当下及未来2-3年的在手订单情况？……（原图原文，照抄）
- **在手订单金额**：xxx
- **在手订单同比变化**：xxx
...（该节点全部原子核对项，一行一个，顺序与题库一致）

#### 分析
（可选展开，不得替代上面的核对项）
```

- 核对项名称**必须与题库一字不差**（装配与闸门按名称匹配，改名 = 漏答）。
- 一个核对项一行，**禁止**把两项写成一句（如"在手订单 123 亿，同此增长 18%"——第二项会被判缺失）。
- 允许在值里带限定语，但值本身必须能独立读懂。

---

## 3. 证据分级

| 级别 | 定义 | 用法 |
|---|---|---|
| A | 公司公告原文、定期报告原文、投资者关系记录表、业绩说明会记录 | 首选，数字类必须尽量落到 A |
| B | 交易所/监管披露、招股说明书、债券募集说明书 | 可用，需注明文件与日期 |
| C | 权威数据机构（Wind/同花顺/巨潮/交易所统计）、券商研报 | 可用，必须具名 + 尽量给链接；标注"第三方口径" |
| D | 媒体转述、行业传闻、未具名"业内人士" | 只能作辅助，不得作为数字的唯一来源 |

每条数字后面写清：**来源名称 + 日期 +（有则）编号或链接**。

---

## 4. 缺口声明（重要）

拿不到数据**不是失败**，写不好才是。合格写法：

> **在手订单金额**：未披露。取数路径：公司未在定期报告中披露在手订单余额；可在"投资者关系活动记录表"（巨潮资讯网 → 公司 → 调研纪要）与季度业绩说明会问答中追踪，最近一期为 2025 年三季报后的调研记录。

不合格写法（会被硬闸门打回）：

- `未披露。`（过短、无路径）
- `未找到相关数据。`（无路径）
- `预计后续会披露。`（用未来叙事回避缺口）

---

## 5. 各主题口径（必须按此计算，并在答案里写明公式）

### 订单面
- **在手订单**：优先取"截至最近一期"的披露值。若公司不披露在手订单，用 **合同负债 + 已公告中标/框架协议金额** 作**代理口径**，并明确标注"代理口径，非披露值"。
- **覆盖倍数** = 在手订单 ÷ 下一年度预期收入（无一致预期则用上一年度收入并注明）。
- **新签增速** = 当期新签 ÷ 上年同期新签 − 1；口径不一致时直接说明不可比。

### 合同约束条款
- 只统计**已公告**的条款；把条款类型、金额/比例、期限分别写清；"有约束力"这类形容词不算答案。

### 研发投入
- 分年给：2023 / 2024 / 2025 前三季度。**绝对金额**取"研发投入"（若报表只有"研发费用"，注明口径差异）。
- **占净利润比重** = 研发投入 ÷ 归母净利润。**净利润为负时该比值不适用**，写明并改用"占营收比重"。
- 资本化率 = 资本化研发投入 ÷ 研发投入总额（未披露资本化则明说）。

### 产能与项目
- **单位产能投资强度** = 总投资额 ÷ 设计产能，单位必须落到 `元/吨`、`元/GWh`、`元/万片` 这类具体量纲，并写出计算式。
- 对比对象必须**具名**（哪家同行、哪个项目、数据年份）；不允许只写"高于行业平均"。

### 减持
- 窗口：2024-01-01 起至基准日。含集中竞价、大宗交易、协议转让、可交换债换股。
- **金额** = 减持股数 × 成交均价；未披露均价的，用公告区间均价并注明"按区间中值估算"。

### 自身造血
- **单季数据**从定期报告倒算：Q2 = 半年报 − 一季报；Q3 = 三季报 − 半年报。写明是倒算值。
- **销售收现比** = 销售商品、提供劳务收到的现金 ÷ 营业收入。连续多季度，标明是否 >100%。
- **存货周转天数** = 平均存货 ÷ 营业成本 × 期间天数；标明是否年化、用的期初期末还是平均。
- **净利/经营现金流** 比值，分母为负时不得直接给比值，需说明。

### 转型与商用
- **U 型反转概率**必须给方法：建议四因子等权（订单覆盖 = 30%、产能利用率 = 25%、经营现金流方向 = 25%、毛利率趋势 = 20%），逐因子打分后给出概率或区间；不许凭空给数。
- "判断行业即将商用"是通用方法论题：给条件清单 + 每条的可量化阈值 + 落到本标的要跟踪的指标。

### 供应链弹性
- 供应商集中度取年报"前五名供应商采购额占比"；无披露则明说。

## 6. 反失败模式（审计员逐条对照）

1. **合并作答**：多个核对项挤进一句话 → 判 partial。
2. **静默省略**：整段跳过某个核对项 → 判 missing。
3. **一句话缺口**：`未披露。` 不带取数路径 → 不合格。
4. **套话填充**："综合来看""整体表现良好""值得关注" 且无数字无来源 → 不合格。
5. **编造**：公告编号、机构名、数字无法回溯 → 不合格（最严重）。
6. **口径错配**：把累计当单季、把营收当收现、把母公司当合并 → 不合格。
7. **未来话术**："预计""有望""后续将"代替当期事实 → 不合格。
8. **张冠李戴**：用行业数据冒充公司数据 → 不合格。
9. **只有结论没有数字**：问数字的核对项给形容词 → 不合格。
10. **只有数字没有来源**：无法回溯 → 不合格。
11. **代理口径冒充披露值**：用了代理口径却不标注 → 不合格。
12. **整车 vs 零部件式错位**：把上游/下游数据当作本体数据 → 不合格。

---

## 7. 引用格式

```
来源：<文件全名>（<日期>，公告编号 <编号>）<链接>
来源：<机构名>（<日期>）<链接>
```

链接能取到就给；取不到就写清"巨潮资讯网 → 公司公告 → 检索关键词"这类可复现路径，同样算合格来源。
