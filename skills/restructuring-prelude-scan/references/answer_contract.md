# 重组前戏 · 点对点回答契约

本文件是作答 agent 与审计 agent 共同的判据。冲突时以此为准。

---

## 1. 唯一目标

**子树里有多少个原子核对项，报告里就有多少行只属于它自己的答案。**

本技能排查的是一类**高度依赖线索、天然带推测成分**的问题。因此除了"一条不漏"，还多一条同等重要的要求：
**每一条信号都必须同时给出反向证据**，否则视为不合格。

---

## 2. 阶段定义（最容易搞错的地方）

| 阶段 | 特征 | 本技能怎么处理 |
|---|---|---|
| **重组前戏** | 正式方案公告**之前**的铺垫动作：聘中介、清壳、卖资产、控股权变更、口径变化、停牌练手等 | 本技能的主战场 |
| **正式重组阶段** | 已公告筹划重大资产重组、已停牌进入程序、已披露预案/草案 | **前戏已结束**。必须在『阶段标注』里注明，不得再把正式公告当作前戏信号堆叠 |
| **重组完成** | 已完成过户/资产交割 | 只做历史回溯，不当作当前信号 |

判定某个信号"是否出现"时，一律限定在**观察窗口**内（默认基准日往前 24 个月，以 run 的 `meta.json` 为准）。

---

## 3. 格式契约

```markdown
### [R01] 突然公告聘请财务顾问、律师等中介机构
- **是否出现**：出现 / 未出现 / 无法判断
- **中介机构与类型**：xxx
...（该信号全部原子核对项，一行一个，顺序与题库一致）

#### 分析
（可选展开，不得替代上面的核对项）
```

- 核对项名称**必须与题库一字不差**；一个核对项一行，禁止合并。
- `是否出现` **只允许三选一**；选『无法判断』必须写明缺什么、去哪查。

---

## 4. 证据分级（每条信号都要标）

| 等级 | 定义 | 能否单独支撑"出现" |
|---|---|---|
| **A** | 公司公告、定期报告、交易所披露、互动平台公司正式回复 | ✅ 可以 |
| **B** | 公开可查数据（行情、工商登记、招聘平台原始页面、债券/授信公开信息） | ✅ 可以 |
| **C** | 媒体转述、研报观点、未具名消息 | ⚠️ 只能作辅助，须标明 |
| **D** | 纯推断（如"招这么多并购岗说明要收购"） | ❌ **不得单独支撑"出现"**，必须标注为推断 |

D 级结论的写法示例：
> 出现（**推断 D 级**）。依据：2026-03 起招聘「并购重组负责人」；**但无任何公告佐证**，也可能只是常规补员。

---

## 5. 反向证据（强制项）

每条信号都必须回答：**这个信号为什么可能不是重组信号？** 常见替代表述要主动排查：

- 聘中介 → 可能为再融资、股权激励、年报审计轮换、诉讼
- 增资/尽调 → 可能为子公司引战投、补充流动资金、常规投后管理
- 清壳 → 可能为集团架构调整、聚焦主业、注销空壳
- 卖资产 → 可能为正常资产处置、盘活低效资产、回笼资金还债
- 现金授信激增 → 可能为募资未投、授信常规续作、季节性备货
- 债务洗澡 → 可能为行业下行被动计提、主动降杠杆
- 债券/质押 → 可能为低息置换高息、补充流动资金、股东自身资金需求
- 股价异动 → 可能为行业普涨、指数同步、题材轮动、业绩驱动
- 控股股东变更 → 可能为国资整合、家族传承、财务投资人到期退出
- 董秘口径变化 → 可能为合规口径收紧、董秘更换导致风格变化
- 停牌 → 可能为监管要求的常规核查、重大合同谈判
- 招聘 → 可能为正常业务扩张、常规补员、第三方代招信息不实

**只写支持证据、不写反向证据的答案，直接判不合格。**

---

## 6. 缺口声明

拿不到数据不是失败，写不好才是。合格写法：

> **具体问答记录**：未获取。取数路径：上证 e 互动（sns.sseinfo.com）→ 搜索公司代码 →「最新问答」按时间倒序翻查 2025-01 至 2026-10；窗口内未发现涉及战略转型/资产整合的回复。

不合格：`未找到。` / `无相关信息。` / `后续可关注。`

---

## 7. 各信号判读口径

| 信号 | 判读要点 | 常见误判 |
|---|---|---|
| R01 聘请中介 | 看公告**怎么描述中介职责**（"为本次重大资产重组提供财务顾问服务"才算强信号） | 把年报审计机构续聘当重组信号 |
| R02 大额增资/尽调 | 看增资对象是**上市公司层面**还是子公司；看是否伴随控制权/董事会安排 | 把子公司引战投当借壳准备 |
| R03 清壳 | 看是否**一次性、成批**处理股权与子公司 | 把单次注销空壳公司当清壳 |
| R04 卖资产 | 看**交易对方背景**（新设主体/无产业背景的接盘方更值得注意）、评估增值率、回款用途 | 把正常处置当卖壳 |
| R05 现金授信 | 看是否**同时**出现现金与授信双升，以及是否与"拟收购"表述同现 | 把募资到账当备战 |
| R06 债务洗澡 | 看计提是否**集中于某一期**、是否伴随管理层变动 | 把行业性亏损当主动洗澡 |
| R07 债券/质押 | 看**控股股东质押比例**变化，而非绝对水平；看募集资金用途 | 把低息置换当资金紧张 |
| R08 股价异动 | 必须给**量化标准**（偏离值/成交额倍数）并剔除行业与指数影响 | 把板块普涨当个股异动 |
| R09 控股股东变更 | 看是否**同时**发生董监高集中换血；看受让方是否有产业背景 | 把二级市场增持当控制权变更 |
| R10 董秘口径 | 要看**同一问题的前后对比**，单次模糊回复不构成信号 | 把合规性套话当信号 |
| R11 停牌 | 区分**小额投资类停牌练手**与**传闻澄清停牌**，统计窗口内次数 | 把一次正常核查当频繁停牌 |
| R12 招聘 | 只能作 D 级推断；须给原始招聘页面与时间 | 把猎头挂单当公司招聘 |

---

## 8. 反失败模式（审计员逐条对照）

1. **合并作答**：多个核对项挤进一句话 → partial
2. **静默省略**：跳过某个核对项 → missing
3. **只找支持证据**：无反向证据 → 不合格（本技能特有）
4. **把 D 级推断当事实**：未标注推断却给出"出现" → 不合格
5. **把正式重组公告当前戏**：阶段判断错误 → 不合格
6. **把行业共性当公司信号**：未剔除板块/指数因素 → 不合格
7. **一句话缺口**：`未披露。` 无取数路径 → 不合格
8. **套话填充**："综合来看值得关注" → 不合格
9. **编造**：公告编号、日期、机构名无法回溯 → 不合格（最严重）
10. **时间越界**：引用观察窗口之外的事件当作本次信号 → 不合格
11. **结论无依据**：给了"出现"却没有任何证据行支撑 → 不合格
12. **汇总表引入新数字**：RB 总表出现正文没有的数字 → 不合格

---

## 9. 引用格式

```
来源：<文件全名>（<日期>，公告编号 <编号>）
来源：<平台名>（<提问/回复日期>）原文：「……」
来源：<数据源>（<日期>）<链接>
```

链接取不到就写可复现路径（如"巨潮资讯网 → 公司公告 → 检索『重大资产重组』"），同样算合格来源。
